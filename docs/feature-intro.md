# 欢欢制卡站 v1.0 — 功能介绍

> AI 驱动的 SillyTavern 角色卡创作平台
> 
> 地址：https://huan.huan.baby

---

## 三种创作入口

### 1. 从零开始制卡

8 步向导式流程，每一步都由 AI 实时生成，流式输出：

| 步骤 | 内容 | 特色 |
|------|------|------|
| 基本信息 | 作品名称、作品类型 | — |
| 角色设定 | 性格、外貌、背景 | 简易模式（自由输入）/ 详细模式（20+ 结构化字段），支持多角色 |
| 世界观 | 时代、地点、规则 | 简易/详细两种模式 |
| 开场白 | 第一条消息 + HTML 美化 | 场景/氛围/篇幅可控，美化支持多种配色和视觉效果 |
| 玩家角色 | {{user}} 的设定 | 可选，简版/详版 |
| 变量/状态栏 | MVU 变量系统 或 纯状态栏 | 双轨可选，预设变量一键加载，MVU 和状态栏分步生成 |
| 额外选项 | 对话语料补充、角色采访 | 可选，提升角色深度 |
| 封面打包 | AI 生成封面 + 导出 PNG | 支持 AI 绘图或手动上传 |

**角色设定方法论：人格拆解法**

不是简单的"性格标签堆砌"，而是一套结构化的性格构建体系：
- **核心驱动** — 角色最深层的性格驱动力
- **日常人格** — 日常表现出的主要性格
- **隐藏面** — 特定条件下才显露的隐藏特质
- **性格展开** — 从核心性格推导出的具体表现（正面展开 / 反面展开 / 跨性格展开）
- **矛盾面** — 看似矛盾但真实存在的特质组合
- **压力模式**（可选） — 不同压力环境下的行为模式切换
- **创作者批注**（可选） — 防止 AI 自动脑补，锚定角色核心

**多角色支持**

- 主角 + 多配角独立管理，每个角色单独填写设定
- 配角世界书分步生成 — 每个配角独立生成/重新生成，不再批量一锅端
- 生成状态追踪 — 已生成/未生成/重新生成 按钮状态清晰
- 删除角色时自动同步状态

### 2. 从小说导入

上传 TXT 小说文件，AI 自动提取世界书：

- **编码检测**：自动识别 UTF-8 / GBK（网文常见编码）
- **章节分割**：正则匹配中文/英文/数字章节标题（"第XX章"、"Chapter X"），识别不到就按段落分组
- **智能分块**：按字数上限合并章节为处理块，可手动调整
- **AI 提取**：逐块提取 5 类信息，SSE 实时显示进度
  - 人物（含阶段性变化、别名、关系网）
  - 世界设定（按类别分组）
  - 时间线事件
  - NPC 动态
  - 因果链（按叙事权重排序：关键 / 推进 / 次要）
- **自动去重**：同名角色合并、世界设定合并、NPC 保留最新状态
- **生成世界书条目**：绿灯（关键词触发）/ 蓝灯（常驻），可逐条编辑后导出

### 3. 和 AI 聊着做

对话式角色卡创作，适合"有个模糊想法但不知道怎么填表"的用户：

- **导入预设**：上传 SillyTavern 预设 JSON → 三层自动解析
  - 解析层：过滤 ST 占位符（marker 条目），提取有效内容
  - 分类层：enabled = 常驻方法论，disabled = 分步引导
  - 运行层：有步骤 → 流水线引导，无步骤 → 自由对话
  - **任何预设都能用**，不绑定特定方法论
- **直接开始**：使用欢欢内置人格拆解法引导
- **流式对话**：AI 逐步收集角色信息，每次只问 1-2 个问题
- **智能提取**：信息足够时 AI 标记完成 → 一键提取为结构化卡片数据 → 进入步骤式流程预览编辑

## 导入已有角色卡

上传 PNG 格式的 SillyTavern 角色卡：
- 自动解析 tEXt chara 元数据块
- 提取角色描述、世界书、开场白、封面图
- **导入的世界书条目永久保留** — 标记为 `imported`，AI 重新生成世界书时不会覆盖
- 填充到编辑界面，可修改后重新导出
- 适合"拿到别人的卡想改改"的场景

## 草稿系统

- **自动保存** — 制卡过程随时保存到浏览器 localStorage
- **多草稿管理** — 最多 20 个草稿，按时间排序
- **完整恢复** — 恢复表单数据、生成结果、世界书条目、角色生成状态
- **模板系统** — 保存常用配置为模板，快速复用

---

## 世界书条目编辑器

不是一个大 textarea 糊弄你，是真正的条目级编辑：

- 每个条目独立显示：名称、关键词、内容、类型、启用状态
- **绿灯**（关键词触发）/ **蓝灯**（常驻生效），一键切换
- 关键词支持逗号分隔，自动拆分
- 添加 / 删除 / 内容实时同步到 Markdown
- 从小说导入和手动创建的条目统一管理

---

## 卡片编辑器 + 版本管理

### 编辑器

对已生成的角色卡进行完整编辑：
- 基础信息（名称、描述）
- 角色描述（Markdown 预览 / 原文编辑切换）
- 开场白（同上）
- 世界书条目（手风琴折叠，条目级编辑）
  - 名称 / 关键词 / 二级关键词
  - 内容 / 启用 / 常驻 / 选择性
  - 位置 / 深度 / 插入顺序 / 角色
  - 支持添加、删除、上下移动
- 正则脚本 / TavernHelper 脚本（只读查看）
- 封面图（预览 + 重新上传）

### 版本管理

- 每次保存自动版本号 +1（v1 → v2 → v3...）
- 保存时自动重建卡片文件（PNG/JSON）
- 版本号显示在卡片列表

### 自动更新推送

导出的每张卡片都内嵌 TavernHelper 自动更新脚本：
- 用户在 SillyTavern 加载卡片时，脚本自动检查 `huan.huan.baby` 上的最新版本
- 发现新版本 → 弹窗确认 → 一键更新到最新版
- 你改了卡片，用户那边直接收到更新，不用重新发卡

## 开场白美化

两种模式：

- **非 MVU**：vanilla JS 渲染静态 HTML，支持配色/效果/布局自定义
- **MVU 版**：jQuery + Mvu 变量系统联动，状态栏数据实时渲染

支持的配色：冷色 / 暖色 / 莫兰迪 / 霓虹 / 森系 / 樱花 / 自定义
支持的效果：渐变背景 / 模糊背景 / 边框光效 / 分隔线装饰

---

## 变量 / 状态栏

### MVU Zod 模式
完整的变量追踪系统：
- Zod Schema 定义变量类型
- 初始值设定
- 更新规则
- HTML 状态栏渲染（独立分步生成）
- 打包为 TavernHelper 脚本 + 世界书条目

### 非 MVU 模式
轻量状态栏：
- `<StatusData>` 块 + 正则隐藏/渲染
- 纯 CSS + vanilla JS，无外部依赖
- 暗色主题友好

预设变量一键加载：当前时间、当前地点、好感度、着装、当前姿势、当前想法、关系状态

## 封面系统

- **AI 生成**：支持 Grok Aurora / NovelAI / Gemini / 自定义图片 API
- **AI 生成标签**：一键让 AI 根据角色设定生成绘图标签
- **手动上传**：JPEG/WebP 等任意格式自动转为 PNG

## API Key 管理

BYOK（Bring Your Own Key），平台不提供 API 额度：

| 类型 | 用途 |
|------|------|
| OpenAI 兼容 | 文本生成（角色设定/世界书/开场白等所有文本步骤） |
| 自定义 AI | 同上，自定义 Base URL |
| Grok Aurora | 图片生成（封面） |
| Gemini | 图片生成 |
| NovelAI | 图片生成（内置模型选择） |
| 自定义图片 | 自定义图片 API |

- API Key 使用 AES 加密存储，不明文保存
- 支持在线拉取模型列表
- 每个用户的 Key 完全隔离

## 输出格式

- **SillyTavern chara_card_v3 spec 3.0** 标准格式
- **PNG 角色卡**：图片 + tEXt 元数据，SillyTavern 直接导入
- 自动附带 CC BY-NC 4.0 协议
- 可选包含：正则脚本 / TavernHelper 脚本 / 世界书 / 开场白美化

---

## 安全与隔离

- **登录**：Discord OAuth 2.0
- **权限**：Discord 身份组验证，指定身份组才能使用
- **数据隔离**：每张卡片、每个 API Key 都绑定用户 ID，用户之间完全隔离
- **传输安全**：HTTPS + secure cookie + trust proxy
- **服务安全**：后端绑定 127.0.0.1，仅通过 Nginx 反代暴露

## 技术栈

- 前端：Vue 3 (CDN) + ES Modules（9 个模块文件）+ marked.js + Lucide SVG Icons，玻璃拟态暗色主题
- 后端：Node.js + Express + better-sqlite3
- AI 接口：OpenAI 兼容 SSE 流式
- 部署：Nginx 反向代理 + systemd
