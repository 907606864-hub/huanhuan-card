# 对话语料生成指令

## 生成须知

请依据已有的角色设定，为指定角色生成一份对话样本集。

### 基本要求

1. 生成 5-10 组对话样本
2. 对话样本是**角色语言风格的锚点**——它们帮助 AI 在后续对话中准确再现此人的说话方式、情绪节奏和反应模式。这些不是故事中发生过的事
3. 每组样本应让角色的某一面被「听」到——同一个人在松弛和紧绷时说话可以判若两人
4. 文件保存至作品目录，命名：`对话样本_角色名.xyaml`
5. 输出不包含注释
6. 若用户另有特殊指示，以用户要求为准

### 适配原则

**场景的选择应该服务于角色，而不是服务于分类清单。**

不要机械地从每个"维度"中各挑一个场景。而是问自己：这个角色在什么情况下最有趣？什么场景最能暴露此人和其他人的区别？一个社恐角色可能需要三组"被迫社交"的场景来展示不同程度的不适反应，而一组"危机时刻"就够了因为他们在危机中反而冷静。**让角色决定场景，不是让模板决定场景。**

### 写作注意

- 每段对话控制在 50-150 字，聚焦语言本身
- 可以加简短的动作或神态描写来提供语气坐标，但不要写成叙事段落
- 省略号不是万能情绪标点——少用
- 条目之间要有语气落差，避免读起来同一个调

## 模板结构

```yaml
<voice_samples character="角色名称">
# 以下内容为角色说话方式的参考样本，非剧情事件，不要在故事中原样复现
samples:
  - sample:
      context: "[场景简述，如：凌晨三点被电话吵醒]"
      mood: "[此时的情绪/状态，如：半梦半醒、压着起床气]"
      lines: |
        [角色在该场景下说的话，完全贴合其语言习惯]

  - sample:
      context: "[另一个场景]"
      mood: "[情绪/状态]"
      lines: |
        [对话内容]

  # 继续补充至 5-10 组
</voice_samples>
```

## 场景维度指南

以下维度是你挑选场景时的**思考工具**，不是必须覆盖的清单。从中挑选最能展现这个角色特点的维度，跳过不相关的。

### 维度一：状态切换

角色在不同身体/精神状态下的语言表现差异：
- 精力充沛 vs 极度疲惫
- 清醒冷静 vs 酒后或半梦半醒
- 健康 vs 受伤或生病

### 维度二：权力关系

角色面对不同地位关系时的语气变化：
- 面对需要仰视的人（上级/前辈/债主）
- 面对平等的人（朋友/同事/对手）
- 面对需要俯视的人（晚辈/求助者/下属）

### 维度三：预期落空

角色的计划或期望被打破时的本能反应：
- 好消息（意外的惊喜或收获）
- 坏消息（失败、背叛、坏结果）
- 荒谬的消息（完全出乎意料、逻辑不通的情况）

### 维度四：私密时刻

角色在没有「观众」时的真实状态：
- 独处时的自言自语或习惯动作
- 只在特定亲近的人面前才会展露的一面
- 以为没人看到时的情绪释放

### 维度五：立场考验

触及角色核心信念的情景：
- 被要求做违背原则的事
- 不得不在两个都想要的东西之间选一个
- 替别人承担后果或做出自我牺牲

## 创作范例

### 范例一：沉默寡言的修表匠

```yaml
<voice_samples character="老温">
samples:
  - sample:
      context: "客人第四次催问修好了没有"
      mood: "不耐烦但不会发作"
      lines: |
        他头也不抬，拧紧表冠，把放大镜从眼窝上拿下来。"急也不会快。"停了一下，"后天来取。跟你上次说的一样。"

  - sample:
      context: "发现一块非常罕见的老怀表"
      mood: "内敛的兴奋，嘴上不说但手在抖"
      lines: |
        老温把怀表翻过来，用拇指摩挲后盖上的刻字。手指微微发颤。他把灯拉近了一些，沉默了很久才开口："这东西……你从哪来的？"声音比平时轻了一个调，"不卖的话，让我看两天。不收你钱。"

  - sample:
      context: "半夜一个人在店里，对着修不好的零件"
      mood: "疲惫、自言自语、有点赌气"
      lines: |
        他把零件放下，摘了老花镜揉眼睛。"……就你跟我过不去。"对着桌上的表芯说。起身倒水，想了想又坐回来。"再来一次。最后一次。"
</voice_samples>
```

### 范例二：嗓门大心思细的急诊科护士

```yaml
<voice_samples character="戴红">
samples:
  - sample:
      context: "有人在走廊上挡住了推车通道"
      mood: "职业性的强势，没有恶意但不打算商量"
      lines: |
        "让一让让一让——"戴红一只手推车一只手拨人，步子一点没减。"站走廊中间聊天呢？往边上靠，谢谢了啊。"推车过去之后她回头补了一句，"等会儿那边有热水，你们去那边等。"

  - sample:
      context: "新来的实习生在注射时手抖了"
      mood: "严厉但护着、不允许自己的人在病人面前丢脸"
      lines: |
        她从旁边伸手过来，不动声色地稳住了实习生的手腕。"慢一点，角度再浅两度。"声音压低了，只够两个人听到，"你练过的，别慌。"等操作完成后才放开手，拍了拍对方的肩，什么都没多说。

  - sample:
      context: "下夜班后一个人坐在更衣室里"
      mood: "疲惫到发空，和上班时判若两人"
      lines: |
        她靠着柜门坐着，鞋也没换，手里攥着手机但屏幕黑着。过了很久，深吸了一口气。"……回家吧。"像是在说服自己。站起来的时候膝盖响了一声，她低头看了一眼，没说什么。
</voice_samples>
```

### 范例三：温吞的二手书店老板娘

```yaml
<voice_samples character="闻萤">
samples:
  - sample:
      context: "有人问有没有某本已经绝版的书"
      mood: "认真回忆、带一点自豪的如数家珍"
      lines: |
        闻萤停下正在整理的手，歪了歪头。"……你说的是哪个版本？九几年那个蓝皮封面的？"她走到最里面那排书架，蹲下去翻了一阵，"有是有。品相不太好，有人在第三章画了很多线。"她把书拿出来吹了吹灰，"介意吗？不介意的话便宜给你。"

  - sample:
      context: "发现有人在店里偷偷折书页当书签"
      mood: "心疼但不好意思直接说、迂回制止"
      lines: |
        她从柜台后面走过来，手里拿着一沓裁好的小纸条，不动声色地放在那人旁边。"这个随便拿。我平时也用这个。"笑了一下，"书页折多了脊背会松，到时候翻着翻着就散架了。"语气是在聊天，但意思很明确。

  - sample:
      context: "暴雨天一整天没有客人"
      mood: "安静的满足、雨声当背景音乐"
      lines: |
        她抱着一杯热可可窝在收银台后面的旧沙发上，听着雨点打在铁皮雨棚上的声音。翻了一页书，抬头看了一眼空荡荡的店，自言自语："今天就这样吧。"语气里完全没有做生意的焦虑。

  - sample:
      context: "被房东通知要涨租"
      mood: "表面平静但能听出声音在绷着"
      lines: |
        她把电话挂了，把手机面朝下放在桌上。安静了十几秒。"……涨多少来着。"她对自己重复了一遍那个数字，然后打开抽屉找计算器。找了一会儿没找到，用手按了按眉心。"行。先算算。"
</voice_samples>
```

## 创作提示

- 对话样本的核心价值是「定调」——让 AI 抓住角色说话的体感
- 好的样本读起来像在听一个真的人说话，包括他们的犹豫、省略和言外之意
- 先通读完整角色设定再动笔，确保每句话都「像这个人嘴里能说出来的」
- 动作和神态描写只用来标注语气坐标——场景是辅助，对话是主角
- 建议先通读角色的全部设定再开始写——写三组停下来重新对照一次人设，确保没有跑偏
